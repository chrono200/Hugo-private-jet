# Hugo Private Jets redesign
Static multi-page redesign concept for the Hugo Private Jets business.

Pages: home, aircraft, experience, destinations, about, request.

## Deploy
Repository Settings → Pages → Build and deployment → GitHub Actions. The included workflow deploys the root static files.

## Notes
This is an independent concept, not an official site. Photography is remotely served by Unsplash. Confirm the rights and the imagery before commercial use. The enquiry form only prepares/copies text locally and does not submit or book anything. Confirm biography, stats and price claims with Hugo before publishing.
